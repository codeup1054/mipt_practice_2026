# T1-MEMO-SKL-01 · Паспорт данных

Описать источник, год, лицензию, единицы и коды пропусков до любого расчёта.

## Когда использовать

В начале работы с новым набором или после смены волны обследования.

## Вход и выход

- **Вход:** файл данных, описание источника
- **Выход:** PASSPORT.md, таблица переменных

## Порядок

1. Указать источник, год, лицензию и дату выгрузки.
2. Записать строки, колонки и единицы измерения.
3. Перечислить коды пропусков и заменить их на NaN.
4. Отметить переменные, которых в наборе нет.

## Проверка

- У каждой ключевой переменной есть единицы и диапазон.
- Коды пропусков перечислены явно.
- Указано, какие переменные отсутствуют.

## Не делать

Не угадывать смысл колонки по названию и не заполнять пропуски средним без правила.
