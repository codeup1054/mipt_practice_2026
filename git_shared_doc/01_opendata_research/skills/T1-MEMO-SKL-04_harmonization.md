# T1-MEMO-SKL-04 · Гармонизация наборов

Сопоставить переменные разных наборов по смыслу и единицам.

## Когда использовать

Перед сравнением BRFSS, NHANES и AI4FoodDB.

## Вход и выход

- **Вход:** две или более таблицы переменных
- **Выход:** таблица соответствия, список несопоставимых

## Порядок

1. Составить таблицу: переменная, набор, единицы, преобразование.
2. Перечислить переменные, которых нет в одном из наборов.
3. Сравнивать только сопоставимые переменные.
4. Добавить оговорку о разных дизайнах.

## Проверка

- Есть таблица соответствия.
- Несопоставимые переменные перечислены отдельно.
- Общий вывод не опирается на разные шкалы.

## Не делать

Не сравнивать возрастные группы и категории дохода без преобразования.
