# T1-MEMO-SKL-09 · Кластеры и профили

Найти устойчивые группы и описать их профиль, а не только номер.

## Когда использовать

Когда популяция неоднородна и нужны сегменты для гипотез.

## Вход и выход

- **Вход:** стандартизованные признаки
- **Выход:** k, silhouette, профили, имена групп

## Порядок

1. Стандартизовать признаки.
2. Посчитать silhouette для k = 2…6.
3. Выбрать k и объяснить цену выбора.
4. Построить профили и назвать группы.

## Проверка

- Признаки стандартизованы.
- Показан silhouette для нескольких k.
- Есть таблица профилей и объяснение имён.

## Не делать

Не называть кластер диагнозом и не выбирать k только по картинке.
