# T1-MEMO-SKL-10 · Отчёт и воспроизводимость

Собрать результат, который можно проверить и повторить.

## Когда использовать

В конце исследования, перед защитой.

## Вход и выход

- **Вход:** ноутбук, метрики, графики
- **Выход:** report.html, README, чек-лист

## Порядок

1. Собрать metrics.json и таблицы.
2. Сверить числа в тексте с метриками.
3. Записать ограничения и границы.
4. Проверить запуск на чистом ядре.

## Проверка

- Числа совпадают с metrics.json.
- README позволяет запустить проект.
- Есть ограничения и чек-лист.

## Не делать

Не оставлять отчёт без ограничений и не хранить ключи в репозитории.
