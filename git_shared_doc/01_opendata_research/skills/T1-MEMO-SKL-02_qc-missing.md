# T1-MEMO-SKL-02 · Контроль качества

Показать пропуски, дубли, диапазоны и выбросы, не потеряв выборку.

## Когда использовать

После загрузки данных и до модели.

## Вход и выход

- **Вход:** таблица данных, правила допустимых значений
- **Выход:** таблица QC, графики

## Порядок

1. Посчитать строки до и после чистки.
2. Показать пропуски по ключевым переменным.
3. Проверить дубли по идентификатору.
4. Сформулировать правило выбросов до расчёта.

## Проверка

- Есть n до и после чистки.
- Пропуски показаны таблицей.
- Правило выбросов записано до результата.

## Не делать

Не удалять выбросы молча и не менять правило после просмотра модели.
