# T1-MEMO-SKL-07 · Бутстрэп и интервалы

Показать неопределённость оценки, а не только точечное значение.

## Когда использовать

После расчёта основного эффекта.

## Вход и выход

- **Вход:** выборка, функция эффекта, число повторов
- **Выход:** 95% CI, распределение эффекта

## Порядок

1. Зафиксировать seed.
2. Сделать 1000+ повторных выборок.
3. Посчитать эффект в каждой.
4. Взять 2,5 и 97,5 процентили.

## Проверка

- Указано число повторов.
- Интервал построен по распределению.
- Вывод учитывает ширину интервала.

## Не делать

Не называть интервал «доверительным», если это стандартная ошибка без квантилей.
