# T1-MEMO-SKL-08 · Метаанализ

Согласовать эффекты разных наборов и показать гетерогенность.

## Когда использовать

Когда один вопрос проверяется на нескольких независимых наборах.

## Вход и выход

- **Вход:** эффекты и стандартные ошибки по наборам
- **Выход:** forest plot, I², общий эффект

## Порядок

1. Собрать эффект и SE по каждому набору.
2. Посчитать fixed и random эффект.
3. Показать I² и forest plot.
4. Объяснить, можно ли делать общий вывод.

## Проверка

- У каждого эффекта есть интервал.
- I² объяснён словами.
- Общий вывод не скрывает гетерогенность.

## Не делать

Не объединять наборы с разными вопросами и единицами.
