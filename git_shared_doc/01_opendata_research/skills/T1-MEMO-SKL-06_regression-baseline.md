# T1-MEMO-SKL-06 · Baseline и регрессия

Сравнить модель с простой базовой линией и проверить утечку.

## Когда использовать

Когда гипотеза проверяется предсказанием или связью признаков.

## Вход и выход

- **Вход:** признаки, целевая переменная, разбиение
- **Выход:** AUC, коэффициенты, важности

## Порядок

1. Сделать baseline: константа или простая модель.
2. Зафиксировать seed и схему кросс-валидации.
3. Обучить основную модель.
4. Проверить, нет ли признаков после целевого события.

## Проверка

- Есть baseline и основная модель.
- Указаны CV и seed.
- Нет утечки целевой переменной.

## Не делать

Не сравнивать AUC без baseline и не подбирать порог по тесту.
