## Правила

- Один раздел — один вопрос исследования. Если на раздел нельзя ответить одним абзацем, раздел делится.
- Каждый расчёт заканчивается текстом: что получилось, в каких единицах, что это значит и чего это не значит.
- Каждый график сохраняется в файл и подписан: что по осям, сколько наблюдений, откуда данные.
- Числа в тексте берутся из вывода ячейки, а не набираются руками: расхождение — ошибка.
- Ноутбук запускается сверху вниз на чистом ядре: скрытых зависимостей от прошлых запусков нет.
- Все пути — относительные от корня проекта; абсолютные пути и чужие диски запрещены.
- Случайность фиксируется: random_state или seed у каждого разбиения, модели и бутстрэпа.
- Секреты и персональные данные в ноутбук не попадают: только имена переменных окружения.

## План исследования

- **-1. Данные уже есть** — «У меня есть данные, исследуй их и предложи гипотезы»
- **0. Постановка целей** — Проблема, вопрос, гипотеза, метод, метрика, важность (цена ошибки)
- **1. Интерактивное планирование** — Гипотезы, какие данные нужны, что проверить первым
- **2. Подготовка и очистка** — Паспорт, коды пропусков, QC, кэш, воспроизводимость
- **3. Анализ данных** — Описательные, гармонизация, PCA, модель, CI, кластеры
- **4. Визуализация** — Один график — один вопрос, оси и единицы, n, вывод
- **5. Комментирование кода** — Заголовки блоков, докстринги, пояснение неочевидных шагов
- **6. Генерация выводов** — Что показали, чего не показали, ограничения
- **7. Подготовка отчёта** — metrics.json, отчёт, README, чек-лист сдачи

## Научный метод

Исследование идёт от наблюдения к проверяемому вопросу, опровержимой гипотезе, заранее выбранному методу и данным, затем к анализу с неопределённостью и выводам с ограничениями. Код, seed и артефакты делают результат воспроизводимым.

1. Наблюдение — что замечено в данных, литературе или практике.
2. Вопрос — один проверяемый вопрос, на который можно ответить данными.
3. Гипотеза — предсказание, которое можно опровергнуть.
4. Метод и данные — дизайн, выборка, переменные и способ анализа до результатов.
5. Анализ — QC, описательные, модель, неопределённость.
6. Выводы — подтвердилась гипотеза или нет, с ограничениями.
7. Воспроизводимость — код, seed, артефакты, чек-лист.

def missing_report(df: pd.DataFrame, cols: list[str]) -> pd.DataFrame:
    rep = pd.DataFrame({
        "непустых": df[cols].notna().sum(),
        "доля": df[cols].notna().mean().round(3),
        "мин": df[cols].min(numeric_only=True),
        "макс": df[cols].max(numeric_only=True),
    })
    return rep.sort_values("доля")

def check_ranges(df: pd.DataFrame, rules: dict[str, tuple[float, float]]) -> pd.DataFrame:
    out = []
    for col, (lo, hi) in rules.items():
        s = df[col].dropna()
        bad = int(((s < lo) | (s > hi)).sum())
        out.append({"колонка": col, "правило": f"{lo}–{hi}", "вне": bad,
                    "мин": float(s.min()) if len(s) else None,
                    "макс": float(s.max()) if len(s) else None})
    return pd.DataFrame(out)

check_ranges(brfss, {"bmi": (10, 80), "MENTHLTH": (0, 30)})

def fisher(r: float, n: int) -> tuple[float, float]:
    """r -> z Фишера и его стандартная ошибка."""
    return float(np.arctanh(r)), float(1 / math.sqrt(max(n - 3, 1)))

def meta_fixed(zs: np.ndarray, ses: np.ndarray) -> dict:
    w = 1 / ses**2
    est = float((w * zs).sum() / w.sum())
    se = float(math.sqrt(1 / w.sum()))
    return {"est": est, "se": se}

def meta_random(zs: np.ndarray, ses: np.ndarray) -> dict:
    fixed = meta_fixed(zs, ses)
    q = float((1 / ses**2 * (zs - fixed["est"])**2).sum())
    dfree = len(zs) - 1
    c = float((1 / ses**2).sum() - ((1 / ses**2)**2).sum() / (1 / ses**2).sum())
    tau2 = max(0.0, (q - dfree) / c) if c > 0 else 0.0
    w = 1 / (ses**2 + tau2)
    est = float((w * zs).sum() / w.sum())
    se = float(math.sqrt(1 / w.sum()))
    i2 = max(0.0, (q - dfree) / q) * 100 if q > 0 else 0.0
    return {"est": est, "se": se, "tau2": tau2, "q": q, "i2": i2}
