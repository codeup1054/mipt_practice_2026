# PASSPORT · каталог блюд NUT-02

**Назначение.** Эталон для сравнения моделей и скиллов распознавания еды.
Один каталог используется во всех прогонах: меняем модель, чат или версию скилла,
но не состав блюд.

## Единицы и правила

- вес порции — **граммы**;
- калории — **ккал на порцию**, не на 100 г;
- белки, жиры, углеводы — **граммы на порцию**;
- состав — список ингредиентов, а не абзац;
- названия ингредиентов нормализуются: нижний регистр, «ё» → «е», без брендов;
- id блюда — латиница, уникальный, без пробелов.

## Состав каталога

В эталоне 8 блюд: греческий салат, боул с киноа, овсяная каша, борщ, суши-сет,
плов, шаурма, пицца Маргарита. Командный каталог расширяется до 20+ блюд:
по 5 блюд от каждого участника.

## Проверка целостности

- у каждого блюда есть фото, вес, КБЖУ, состав и источник;
- макросы сходятся с калориями в пределах 10 %;
- нет дублей id и повторных фото;
- для каждого блюда указано, что именно взвешивали (готовое блюдо или ингредиенты).

## Ограничения

КБЖУ — оценка по открытым источникам, а не лабораторный анализ. Вес и состав
по фото приблизительны. Расхождения фиксируются в отчёте, а не подгоняются.
