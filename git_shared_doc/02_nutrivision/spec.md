# NUT-02 · Нутриентный анализ еды

Спецификация референсного исследования: что сравниваем, на каких данных, какими
метриками и что считается результатом.

## Вопрос

Что сильнее влияет на качество нутриентного анализа — модель, чат или сам скилл
распознавания? И как доказать это числами, а не впечатлением?

## Гипотезы

| Код | Гипотеза | Чем проверяем |
|---|---|---|
| H1 | Доработка скилла v1 → v2 даёт больший прирост, чем смена модели | схема A, MAE % |
| H2 | Разница моделей при одном скилле больше разницы чатов | схемы B и C |
| H3 | Клиент (CLI против веб) не даёт значимой разницы | схема C, t-критерий |

## Данные

- **Эталон:** 8 блюд из задания, у каждого фото, вес, КБЖУ, состав и NDI.
- **Командный каталог:** 5 блюд от каждого участника, всего 20+.
- **Эталонные источники:** открытые меню, USDA FoodData Central, Open Food Facts.
- **Единицы:** вес — граммы, калории — на порцию, Б/Ж/У — граммы.
- **Паспорт:** `processed/PASSPORT.md`, каталог — `processed/food_catalog.json`.

## Схемы сравнения

| Схема | Что меняем | Что проверяем |
|---|---|---|
| A | скилл v1 → v2 на одной модели | вклад доработки навыка |
| B | модель A → B на одном скилле | разницу моделей |
| C | CLI → веб на одном скилле | влияние клиента |
| D | 2×2: модели × скиллы | взаимодействие факторов |

Один каталог, один промпт, одна переменная за раз. Сырые ответы —
в `out/runs/<model>-<chat>-<skill>/predictions.csv`.

## Метрики

| Метрика | Формула | Порог |
|---|---|---|
| MAE % | `mean(abs(pred_kcal - ref_kcal) / ref_kcal) × 100` | ≤ 15 % |
| Match % | доля эталонных ингредиентов, найденных в ответе (recall) | ≥ 80 % |
| t-критерий | одновыборочный двусторонний по `err_pct`, H₀: смещения нет | `|t| > t(0.975, df)` |
| Боксплот | нормированное отклонение калорий по блюдам | выбросы объяснены |

Для 23 блюд критическое значение 2,074; для 8 блюд — 2,365. Код считает порог
по фактическому `df`, а не хардкодит 2,074.

## Ограничения

Восемь блюд в эталоне мало для сильного статистического вывода; состав и вес по фото
приблизительны; модели могли видеть похожие блюда в обучении. Это расчёт КБЖУ и
ингредиентов, а не медицинская рекомендация: решение о питании принимает человек
вместе с врачом.
