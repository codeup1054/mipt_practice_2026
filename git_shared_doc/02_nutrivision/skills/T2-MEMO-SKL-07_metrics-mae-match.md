# T2-MEMO-SKL-07 · MAE % и Match %

Посчитать ошибку калорий и полноту ингредиентов по блюдам.

## Когда использовать

После прогонов.

## Вход и выход

- **Вход:** predictions.csv, эталон
- **Выход:** metrics.json, сводка

## Порядок

1. Соединить ответы с эталоном по dish_id.
2. Посчитать err_pct и abs_err_pct.
3. Посчитать Match % как долю найденных ингредиентов.
4. Агрегировать по варианту и указать n.

## Проверка

- Метрики по каждому блюду.
- Указано n.
- Пороги 15% / 80% проверены.

## Не делать

Не считать MAE только по среднему без разброса.
