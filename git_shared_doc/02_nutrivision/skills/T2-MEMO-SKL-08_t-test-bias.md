# T2-MEMO-SKL-08 · Критерий Стьюдента

Проверить систематическое смещение калорий.

## Когда использовать

После расчёта err_pct.

## Вход и выход

- **Вход:** err_pct по варианту
- **Выход:** t, p, df, 95% CI

## Порядок

1. Сформулировать H₀: смещения нет.
2. Посчитать t и p.
3. Взять критическое значение по df.
4. Добавить интервал и вывод.

## Проверка

- H₀ названа.
- df и порог указаны.
- p интерпретирован, а не только приведён.

## Не делать

Не использовать 2,074, если df не 22.
