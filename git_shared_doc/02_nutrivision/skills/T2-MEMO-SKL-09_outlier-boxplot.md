# T2-MEMO-SKL-09 · Выбросы на боксплоте

Показать разброс и объяснить выбросы.

## Когда использовать

После метрик по блюдам.

## Вход и выход

- **Вход:** err_pct по вариантам
- **Выход:** боксплот, список выбросов

## Порядок

1. Построить боксплот.
2. Добавить линии 0 и ±15%.
3. Найти |err| > 25%.
4. Объяснить каждый выброс.

## Проверка

- Подписаны оси и n.
- Выбросы перечислены.
- Ни один не удалён молча.

## Не делать

Не удалять сложные блюда, чтобы улучшить среднее.
