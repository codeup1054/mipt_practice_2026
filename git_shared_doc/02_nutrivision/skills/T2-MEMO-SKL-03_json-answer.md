## Вход и выход

- **Вход:** фото, вес
- **Выход:** components[], kcal, Б/Ж/У, confidence, notes

## Порядок

1. Проверить обязательные поля.
2. Проверить типы и диапазоны.
3. Проверить confidence в 0…1.
4. Сохранить сырой ответ.

## Проверка

- Все поля на месте.
- Типы соответствуют схеме.
- Ответ сохранён в out/runs.

Не принимать свободный текст вместо JSON.
