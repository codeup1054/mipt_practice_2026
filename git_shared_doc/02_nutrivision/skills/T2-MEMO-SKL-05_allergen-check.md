# T2-MEMO-SKL-05 · Аллергены

Отметить вероятные аллергены в notes.

## Когда использовать

После распознавания состава.

## Вход и выход

- **Вход:** components[]
- **Выход:** notes с аллергенами

## Порядок

1. Проверить орехи, молоко, глютен, яйца, рыбу.
2. Указать только вероятные, не выдуманные.
3. Не давать медицинских рекомендаций.

## Проверка

- Аллергены в notes.
- Нет диагнозов и назначений.
- Формулировка осторожная.

## Не делать

Не писать «безопасно для аллергика».
