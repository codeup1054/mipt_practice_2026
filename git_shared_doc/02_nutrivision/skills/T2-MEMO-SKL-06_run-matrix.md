# T2-MEMO-SKL-06 · Матрица прогонов

Сравнить модели и чаты на одном каталоге и промпте.

## Когда использовать

Перед расчётом метрик.

## Вход и выход

- **Вход:** каталог, промпт, модели, чаты
- **Выход:** out/runs/<variant>/predictions.csv

## Порядок

1. Зафиксировать один каталог и один промпт.
2. Сделать минимум 2 модели × 2 чата.
3. Сохранить сырые ответы.
4. Отметить отказы и ошибки.

## Проверка

- Один каталог и промпт.
- Минимум 2×2.
- Сырые ответы сохранены.

## Не делать

Не менять промпт между вариантами.
