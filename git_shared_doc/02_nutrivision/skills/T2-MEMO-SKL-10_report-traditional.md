# T2-MEMO-SKL-10 · Отчёт и традиционный способ

Собрать отчёт с числом, ограничениями и сравнением с ручным способом.

## Когда использовать

В конце NUT-02.

## Вход и выход

- **Вход:** metrics.json, factors.csv, графики
- **Выход:** report.html, README

## Порядок

1. Сверить числа с metrics.json.
2. Описать, что дало больше: модель или навык.
3. Добавить раздел «Традиционный способ».
4. Записать ограничения и что дальше.

## Проверка

- Числа совпадают.
- Есть раздел «Традиционный способ».
- Есть ограничения.

## Не делать

Не писать «ИИ решил» без числа, метода и границы.
