# T2-MEMO-SKL-02 · Проверка порции

Сверить сумму веса компонентов с весом порции.

## Когда использовать

После ответа модели с компонентами.

## Вход и выход

- **Вход:** components[], вес порции
- **Выход:** флаг расхождения, notes

## Порядок

1. Сложить weight_g компонентов.
2. Сравнить с весом порции.
3. Если расхождение > 15%, добавить notes.
4. Не исправлять ответ молча.

## Проверка

- Сумма веса посчитана.
- Расхождение объяснено.
- Исходный ответ сохранён.

## Не делать

Не подгонять вес под эталон после просмотра калорий.
