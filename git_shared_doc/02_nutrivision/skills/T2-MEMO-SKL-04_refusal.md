# T2-MEMO-SKL-04 · Отказ при нераспознанном блюде

Не выдумывать калории, если блюдо не распознано.

## Когда использовать

Когда модель не уверена или на фото нет еды.

## Вход и выход

- **Вход:** фото, confidence
- **Выход:** error: not_food | low_confidence

## Порядок

1. Проверить, есть ли блюдо на фото.
2. Если нет — вернуть not_food.
3. Если уверенность низкая — low_confidence.
4. Не добавлять выдуманные калории.

## Проверка

- Отказ имеет код.
- В отказе нет случайных КБЖУ.
- Отказ виден в таблице прогонов.

## Не делать

Не превращать отказ в «примерно 300 ккал».
