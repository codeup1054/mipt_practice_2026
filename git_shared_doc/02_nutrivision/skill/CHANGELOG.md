# CHANGELOG · nutriment-recognition

## 2.0.0 — 2026-11-27

- Строгая JSON-схема: `components[]`, КБЖУ, `confidence`, `notes[]`.
- Отказ `not_food` и `low_confidence` вместо выдуманных калорий.
- Проверка суммы веса компонентов (расхождение > 15 % — в `notes`).
- Аллергены в `notes`.
- Запрет медицинских рекомендаций.

## 1.0.0 — 2026-11-25

- Первая версия: список ингредиентов и калории свободным текстом.
- Нет проверки порции и отказа; сравнение между моделями затруднено.
