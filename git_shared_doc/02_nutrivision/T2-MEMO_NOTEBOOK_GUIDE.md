## Правила

- Один каталог и один промпт: меняем одну переменную за раз, иначе разница моделей смешивается с разницей инструкций.
- Скилл возвращает строгий JSON; свободный текст не сравнивается между моделями.
- Сырые ответы сохраняются в out/runs/<вариант>/ — метрики считаются из них, а не из пересказа.
- MAE % и Match % считаются по каждому блюду, затем агрегируются по варианту.
- t-критерий проверяет систематическое смещение; порог берётся по фактическому числу степеней свободы.
- Выбросы объясняются, а не удаляются: сложный состав, соус, неточный вес.
- Числа в тексте берутся из metrics.json и factors.csv, а не набираются руками.
- Это расчёт КБЖУ и ингредиентов, а не медицинская рекомендация.

## Научный метод

Исследование идёт от наблюдения к проверяемому вопросу, опровержимой гипотезе, заранее выбранному методу и данным, затем к анализу с неопределённостью и выводам с ограничениями. Код, seed и артефакты делают результат воспроизводимым.

1. Наблюдение — что замечено в данных, литературе или практике.
2. Вопрос — один проверяемый вопрос, на который можно ответить данными.
3. Гипотеза — предсказание, которое можно опровергнуть.
4. Метод и данные — дизайн, выборка, переменные и способ анализа до результатов.
5. Анализ — QC, описательные, модель, неопределённость.
6. Выводы — подтвердилась гипотеза или нет, с ограничениями.
7. Воспроизводимость — код, seed, артефакты, чек-лист.

## 6. t-критерий

- **Какой порог при нашем числе блюд?** — 2,074 — только для df ≈ 22
- **Что означает p > 0,05?** — это не доказательство отсутствия ошибки

### Действия

1. Посчитать t и p по err_pct каждого варианта.
2. Взять критическое значение по df.

4. Записать решение: значимо или в пределах шума.

- [ ] H₀ сформулирована словами.
- [ ] Указаны n, df и критическое значение.
- [ ] Есть p и интерпретация, а не только t.

    if a not in pivot.columns or b not in pivot.columns:
        return None
    diff = (pivot[a] - pivot[b]).dropna()
