# 02_nutrivision · T2-MEMO · Нутриентный анализ еды (NUT-02)

**Код памятки:** `T2-MEMO`. Примеры навыков: `skills/`, коды `T2-MEMO-SKL-01…10`.

Референсный ноутбук: **что сильнее влияет на качество — модель, чат или навык (skill)
распознавания**. Внутри — каталог блюд, схема навыка (skill), прогоны, MAE %, Match %,
t-критерий, боксплот, тепловая карта ошибок и вывод.

## Файлы

| Файл | Что внутри |

Гид по ноутбуку: [`T2-MEMO_NOTEBOOK_GUIDE.html`](T2-MEMO_NOTEBOOK_GUIDE.html).

## Примеры навыков (skills)

Десять учебных `SKILL.md` в папке `skills/`: каталог, проверка порции, JSON-схема, отказ, аллергены, матрица прогонов, MAE/Match, критерий Стьюдента, выбросы и отчёт. Начните с `skills/README.md`.

## Запуск

```bash
cd 02_nutrivision
jupyter execute NUT02_REFERENCE.ipynb
```

Или откройте ноутбук в VS Code / Jupyter и выполните сверху вниз.

## Демо-прогоны

Если в `out/runs/*/predictions.csv` нет реальных ответов, ноутбук собирает
**демонстрационные** данные (`out/runs_demo.csv`) и пишет `runs_source: "demo"`
в `metrics.json`. Демо показывает расчёт, но **не заменяет сдачу**: нужны
минимум две модели и два чата.

## Что показать в портфолио

- навык (skill) со строгим JSON, отказом и версией;
- один каталог и один промпт, одна переменная за раз;
- MAE % и Match % по каждому блюду, а не только средние;
- t-критерий с порогом по `df` и доверительным интервалом;
- тепловая карта ошибок и объяснение выбросов;
- вывод «навык или модель» с размером эффекта и границей применимости.

## Ограничения

Восемь блюд в эталоне мало для сильного статистического вывода; состав и вес по фото
приблизительны; модели могли видеть похожие блюда в обучении. Это расчёт КБЖУ и
ингредиентов, а не медицинская рекомендация.
